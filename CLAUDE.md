# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

R + Quarto analysis of the Welsh default 20mph speed limit (policy date `2023-09-17`). Design: within-Wales difference-in-differences on roads that were 30mph pre-policy — treated = roads cut to 20mph, control = 30mph "exception" roads. Wales-vs-England comparison was rejected. Full rationale, outcomes and data dead-ends are in @research-design-notes.md — read it before proposing design or data changes.

- Inferring treatment from a 30→20 switch in STATS19 `speed_limit` conditions on the outcome; use it only as a validation cross-check, never as the treatment assignment.
- The estimation approach (panel unit, estimator/package) is **not decided**. When asked for modelling code, propose options with tradeoffs rather than assuming one.

## Running

- Render: `quarto render WalesSpeedLimit.qmd` (no `_quarto.yml`; paths are relative to the project root). Rendering rewrites `data/wales_30mph_exceptions.rds`.
- Download/processing chunks are `eval: false` on purpose (multi-GB STATS19 downloads, 0.5–1 GB rds files). **Never flip them to `eval: true`.** Run pieces in an Rscript/console only when explicitly asked.
- `data/wales_30mph_exceptions.csv` is hand-compiled from council sources (not generated by code). `status` values: `original_exception`, `reverted_after_review`, `proposed_not_confirmed` (exclude from core analysis), `unclear`. AI-extracted rows need spot-checking against `source_url`.

## Code style

- Native pipe `|>`, tidyverse/readr functions (`read_csv`, `write_rds`, `if_else`); `janitor::clean_names()` right after every read.
- snake_case; `_raw` = GB-wide, `_wales` = filtered to Wales (e.g. `collisions_raw` → `collisions_wales`).
- Every chunk gets `#| label:` (kebab-case) and an explicit `#| eval:`.
- UK English in prose and comments.

## Git and data

- Keep data out of git: never commit `data/raw/`, `.RData`, `.rds` or `.zip` files. They are gitignored and have been removed from history, so check `git status` before committing to make sure no data file is staged.
- No remote is configured.

## Editing gotcha

The user keeps `WalesSpeedLimit.qmd` open in RStudio, and saving there can overwrite Claude's edits with a stale buffer. After editing a file that may be open in RStudio, remind the user to use File > Reload before saving.
